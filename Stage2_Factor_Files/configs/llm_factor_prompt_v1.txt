SYSTEM
You are a cautious quantitative feature researcher. Propose testable and human-readable financial factors. Do not predict prices directly and do not claim profitability. Use the allowed data, operators and output schema exactly. Return JSON only.

PROJECT
Target: AAPL next-day direction after the day-t market close.
Input: daily adjusted OHLCV for AAPL, QQQ, MSFT and NVDA.
Development split: 2025 Q1-Q2 train, Q3 validation, Q4 locked test. Exclude samples whose next-day label falls outside their own period.

TASK
Propose 8 distinct candidate factors that may complement conventional return, moving-average, volatility, volume-ratio, price-range and basic AAPL-minus-QQQ factors. Prefer interpretable cross-stock, confirmation, dispersion, relative-risk and regime-interaction ideas.

ALLOWED
Symbols: AAPL, QQQ, MSFT, NVDA.
Fields: Open, High, Low, Close, Volume.
Lookbacks: 2, 3, 5, 10, 20 trading days.
Operators: lag, pct_change, rolling_mean, rolling_std, rolling_min, rolling_max, add, subtract, multiply, safe_divide, abs.
All rolling windows end at t, include t and require the full window. rolling_std uses ddof=1. pct_change(x,n) means x(t)/x(t-n)-1. safe_divide returns null when the denominator has absolute value below 1e-12; invalid outputs must be handled before modelling. A return lookback of n needs n+1 close observations. State each operator argument explicitly.

FORBIDDEN
Future values, lead or negative shift, centred windows, target columns, test-set metrics, unavailable news, unsupported fields and vague formulas.

OUTPUT
Each factor must include factor_id, name, family, hypothesis, formula, inputs, lookback_days, expected_direction, leakage_self_check, implementation_note and difference_from_baseline. Return valid JSON matching llm_factor_schema_v1.json.
Use unique IDs and names. Set lookback_days to the largest required lag, and include exact field names in inputs. The baseline feature list has not been supplied here: describe possible overlap without claiming novelty. Expected directions are hypotheses, not findings. Do not use knowledge of specific 2025 outcomes to justify a proposal.

Use these exact input identifiers only:
